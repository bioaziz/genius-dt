# Tools and Technologies

| Technology | Category | Purpose | Key Features |
|------------|----------|---------|-------------|
| **Three.js** | 3D Graphics | Interactive visualization of the elevator environment | - WebGL-based rendering<br>- Camera controls<br>- Mesh animations<br>- Material effects<br>- Dynamic scene manipulation |
| **TypeScript** | Programming Language | Structured development with type safety | - Static type checking<br>- Enhanced code organization<br>- Better IDE support<br>- Improved maintainability |
| **MQTT Protocol** | Communication | IoT data transmission | - Lightweight publish-subscribe messaging<br>- Minimal latency<br>- Reliable data delivery<br>- Ideal for IoT applications |
| **Tailwind CSS** | UI Styling | Rapid interface development | - Utility-first approach<br>- Consistent component styling<br>- Responsive design<br>- Minimal CSS overhead |
| **ECharts** | Data Visualization | Dynamic dashboards and charts | - Real-time data visualization<br>- Sensor line charts<br>- Heatmaps<br>- Interactive data exploration |
| **Vite** | Development Environment | Modern build tooling | - Fast startup<br>- Hot module replacement (HMR)<br>- Optimized output<br>- TypeScript integration |
