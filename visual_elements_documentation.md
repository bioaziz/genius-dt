## Integration Instructions

### For Mermaid Diagrams
The `.mmd` files contain Mermaid syntax for creating diagrams. To integrate these into your thesis:

1. **Option 1: Use Mermaid Live Editor**
   - Go to [Mermaid Live Editor](https://mermaid.live/)
   - Copy the content of the `.mmd` file into the editor
   - Export as PNG or SVG
   - Insert the exported image into your document

2. **Option 2: Use Mermaid Plugin for Document Editor**
   - If your document editor supports Mermaid (or has a plugin), you can directly paste the Mermaid code

### For Markdown Tables
The `.md` files contain tables in Markdown format. To integrate these into your thesis:

1. **Option 1: Convert to Document Format**
   - Copy the table content
   - Use an online Markdown to Word/PDF converter
   - Insert the converted table into your document

2. **Option 2: Manual Recreation**
   - Use the markdown tables as a reference
   - Recreate them in your document editor's native table format
